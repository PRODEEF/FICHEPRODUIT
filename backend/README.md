# Backend

NestJS backend application with Fastify adapter.

## Setup

```bash
cp .env.example .env
npm install
```

## Running

```bash
# Development
npm run start:dev

# Production
npm run build
npm run start:prod
```

## API Documentation

Swagger docs are available at `http://localhost:3000/api/docs` when the server is running.

## Testing

```bash
# Unit tests
npm test

# E2E tests
npm run test:e2e
```
